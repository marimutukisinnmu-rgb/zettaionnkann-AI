# 絶対音感AI

WAVなどの音声ファイルから、単音の音名とMIDIノート番号を推定するPythonプロジェクトです。v0.3ではFFTを中核に残し、複数の信号解析器を組み合わせるハイブリッド構成にしました。

## v0.3の解析方式

- **FFT（長時間窓）**：基音周波数付近のスペクトル成分を調べます。長い観測時間を使い、FFTサイズを大きくして周波数グリッドを細かくしています。
- **倍音テンプレート照合**：基音だけでなく、2倍・3倍・4倍……の周波数成分をまとめて評価します。
- **奇数倍音の補助評価**：3倍・5倍などの成分を使い、上の音の偶数倍音だけで説明できるオクターブ下候補を慎重に評価します。
- **自己相関**：波形の周期性を調べます。短いラグで相関が高くなる低音の誤判定を避けるため、局所的な谷と次のピークを利用し、主に低〜中音域で使います。
- **YIN**：差分関数とCMNDに基づく周期推定を使用します。非常に高い音では周期が数サンプルしかなく誤判定しやすいため、YIN単独で全音域を決めない設計です。
- **CQT**：MIDI 0〜127に対応する128個の対数周波数ビンを解析します。
- **Attack / Sustain分離**：音の立ち上がりと持続部分を別々にFFT解析し、音色の時間変化を取り込みます。
- **信頼度スコア統合**：各解析器のスコアを重み付けして統合し、ExtraTreesの予測も補助的に使います。
- **オクターブ補正**：奇数倍音の裏付けがある場合だけ、オクターブ下候補を小さく補正します。

## 動作環境

Python 3.10以降を推奨します。

## インストール

```powershell
python -m pip install numpy librosa scikit-learn joblib soundfile
```

## 解析設定

- サンプルレート：44,100 Hz
- 長時間FFTサイズ：131,072
- Attack FFTサイズ：32,768
- 最大観測時間：2.5秒
- CQT：128 bins、1オクターブあたり12 bins、hop_length 4,096
- 対象MIDIノート：0〜127

FFTのゼロパディングは周波数グリッドを細かくしますが、それだけで本来の周波数分解能が増えるわけではありません。低音の分解能には、実際に含まれる音声の観測時間も重要です。この実装では最大2.5秒を解析します。音源自体が短い場合、ゼロパディングで失われた情報を復元することはできません。

44,100 Hzのナイキスト周波数は22,050 Hzなので、MIDI 127（G9、約12,544 Hz）の基音はサンプリング上の範囲内です。ただし、元WAVのサンプルレートが低い場合、44,100 Hzへ変換しても失われた高周波情報は戻りません。

## 初回起動・学習

```powershell
python main.py
```

学習モデルがない場合、128音それぞれの合成サンプルを生成してExtraTreesモデルを自動学習し、`models/pitch_ai.pkl` に保存します。

モデルを作り直す場合：

```powershell
python main.py --retrain
```

v0.3は旧バージョンと特徴量の構成が異なります。古いモデルを検出した場合は自動的に新形式で再学習します。

## 音声ファイルを判定

```powershell
python main.py "test.wav"
```

結果には、最終音名、MIDI番号、周波数、オクターブ補正の有無、各解析器の個別推定、DSP統合結果、ML結果、上位5候補が表示されます。

## ベンチマーク

`benchmark.py` は指定WAVフォルダのファイル名から正解音名を読み取り、全楽器番号をまとめて評価します。

既定のWAVフォルダ：

```text
E:\rise-\temp\midi音\wav
```

ファイル名形式：

```text
(楽器番号) - (Notes番号) - (音名).wav
```

例：

```text
000 - 001 - C#-1.wav
000 - 002 - D-1.wav
```

実行：

```powershell
python benchmark.py
```

結果は `benchmark_results.txt` に保存されます。実行開始時に既存ファイルを上書きするため、過去の結果を残したい場合は先に別名でコピーしてください。Ctrl+Cで途中停止した場合も、そこまでの結果はログに残ります。

## 注意・既知の制約

- 現在は**単音の推定**を主な対象にしています。和音や複数音が同時に鳴る音源を完全に分離して採譜する機能ではありません。
- 学習データは音色をランダム化した合成音です。合成音での学習・スモークテストが、実際のピアノやGM音源での正解率を保証するわけではありません。
- 楽器によって基音が弱い、倍音が強い、アタックが特殊などの違いがあり、解析器ごとに誤判定する場合があります。最終的な性能は同じ実音源ベンチマークで比較してください。
- YINと自己相関は、音域や音色によって信頼性が変わります。高音域ではFFT/CQTを優先するようにしています。
- 解析器を増やしたため、v0.2より初回学習と1ファイルあたりの解析に時間がかかります。
