# 絶対音感AI

音声ファイルを入力し、含まれる音の音名を推定するPythonプロジェクトです。

## 主な機能

- 音声ファイルから音程を推定
- DSP（信号処理）と機械学習（ML）を組み合わせた判定
- MIDIノート番号 0～127 を対象
- 学習モデルが存在しない場合は、自動で学習データを生成して学習
- WAVファイルを使ったベンチマーク

## 動作環境

Python 3 が必要です。

## インストール

プロジェクトのフォルダで、次のコマンドを実行します。

```powershell
python -m pip install numpy librosa scikit-learn joblib
```

## 初回起動・学習

```powershell
python main.py
```

学習済みモデルがない場合、自動で学習を行い、モデルを `models/pitch_ai.pkl` に保存します。

学習済みモデルを作り直す場合：

```powershell
python main.py --retrain
```

## 音声ファイルを判定

```powershell
python main.py "test.wav"
```

判定結果には、推定音名、MIDI番号、周波数、DSPとMLそれぞれの判定、および候補上位5件が表示されます。

## ベンチマーク（楽器番号000）

`benchmark.py` は、指定されたWAVフォルダから楽器番号 `000` のファイルを探し、AIの推定結果とファイル名に含まれる音名を比較します。

### WAVファイルの配置

既定の対象フォルダ：

```text
E:\rise-\temp\midi音\wav
```

ファイル名は次の形式です。

```text
(楽器番号) - (Notes番号) - (音名).wav
```

例：

```text
000 - 001 - C#-1.wav
000 - 002 - D-1.wav
000 - 003 - D#-1.wav
```

### 実行

```powershell
python benchmark.py
```

テスト結果は `results_000.csv` に保存されます。コンソールには各ファイルの正解音名・予測音名と、全体の正解数・不正解数・正解率が表示されます。

## 注意

- ベンチマークの正解音名は、ファイル名の3番目の項目から取得します。
- 現在の `benchmark.py` は楽器番号 `000` のみを対象にしています。
- 合成音で学習したモデルの性能と、実際の楽器音に対する判定精度は同じではありません。複数の音源・楽器でテストし、結果を確認してください。
