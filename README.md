# 絶対音感AI

音声ファイルを入力し、含まれる音の音名を推定するPythonプロジェクトです。

## 主な機能

- 音声ファイルから音程を推定
- DSP（信号処理）と機械学習（ML）を組み合わせた判定
- MIDIノート番号 0～127 を対象
- 学習モデルが存在しない場合は、自動で学習データを生成して学習
- WAVファイルを使った複数楽器のベンチマーク
- ベンチマーク中の出力をコンソールとTXTへ同時にストリーミング保存
- ベンチマーク開始時にモデルを1回だけ読み込み、全WAVで使い回す

## 動作環境

Python 3 が必要です。

## インストール

プロジェクトのフォルダで、次のコマンドを実行します。

```powershell
python -m pip install numpy librosa scikit-learn joblib
```

## 解析設定

現在の解析設定：

- サンプルレート：44,100 Hz
- FFTサイズ：65,536
- MIDIノート番号 0～127 を解析対象

44,100 Hz のナイキスト周波数は 22,050 Hz なので、MIDI 127（G9、約12,544 Hz）の基音もサンプリング上の解析範囲に入ります。

**解析設定を変更した後は、既存モデルを使わず必ず再学習してください。**

## 初回起動・学習

```powershell
python main.py
```

学習済みモデルがない場合、自動で学習を行い、モデルを `models/pitch_ai.pkl` に保存します。

学習済みモデルを作り直す場合：

```powershell
python main.py --retrain
```

## 音声ファイルを判定

```powershell
python main.py "test.wav"
```

判定結果には、推定音名、MIDI番号、周波数、DSPとMLそれぞれの判定、および候補上位5件が表示されます。

## ベンチマーク（全楽器番号）

`benchmark.py` は、指定されたWAVフォルダからファイル名に含まれる楽器番号を自動検出し、見つかった全楽器番号を順番にテストします。

### WAVファイルの配置

既定の対象フォルダ：

```text
E:\rise-\temp\midi音\wav
```

ファイル名は次の形式です。

```text
(楽器番号) - (Notes番号) - (音名).wav
```

例：

```text
000 - 001 - C#-1.wav
000 - 002 - D-1.wav
001 - 001 - C#-1.wav
001 - 002 - D-1.wav
```

### 実行

```powershell
python benchmark.py
```

### 出力

結果はプロジェクト直下の `./benchmark_results.txt` に保存されます。

- コンソールの `print()` 出力と同じ内容をTXTにも書き込みます。
- 1行ごとに即時フラッシュするため、実行中もTXTに結果が反映されます。
- ベンチマーク開始時にTXTを新規作成（上書き）します。
- 途中で Ctrl+C で停止しても、それまでの結果はTXTに残ります。
- 楽器ごとの正解数・不正解数・正解率と、全体の集計を表示します。
- AIモデルは最初に1回だけ読み込み、すべてのWAVで使い回します。

## 注意

- ベンチマークの正解音名は、ファイル名の3番目の項目から取得します。
- ファイル名の形式に一致しないWAVはスキップされます。
- 合成音で学習したモデルの性能と、実際の楽器音に対する判定精度は同じではありません。複数の音源・楽器でテストし、結果を確認してください。
